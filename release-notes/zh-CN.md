# ShareToken 1.0.2

更快、更省流量，断线自动续传。

## 性能提升
- 回答改用压缩后的二进制帧传输，经中继的流量降到原来的约 1/8。
- 请求先压缩再发送，长对话历史的上传量降到约 1/4；请求上限提高到 32 MB。
- 同一段对话的后续请求优先回到上次的节点，prompt 缓存更容易命中。

## 稳定性提升
- 中继重启或网络切换时，正在输出的回答会在 60 秒内自动接上。
- 模型长时间思考时有心跳，不再被误判为卡死。
- 点停止后，节点立即停止生成，只按已送达的部分计费。

## 安全性
- 中继无法再从数据包大小推测每个 token 的长度。

**本版本更新了通信协议，1.0.1 及更早的版本不能再连接网络，请升级。**
