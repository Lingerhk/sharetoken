# ShareToken 1.0.1

新增共享伙伴，桌面应用升级到 Wails v3。

## 共享伙伴
- 配对成为共享伙伴后，双方可以共享对方的 token 资源；伙伴节点不可用时，自动切换回 P2P 网络
- 可以限制给出去的量：每 24 小时的 tokens 上限和每个节点的并发比例，比例设为 0 即暂停共享
- 打开「只用伙伴的节点」后不再到网络上购买；在 配对 → 共享伙伴，或用 `sharetoken partner`

## 登录与账户
- 不再使用密码：输入邮箱和收到的验证码即可登录，新邮箱自动注册
- 可以开启两步验证

## 桌面应用
- 新界面：升级到 Wails v3，窗口更小，带侧边栏导航和状态栏
- 菜单栏显示当前中继、延迟、共享状态和可用 credit；Linux 支持托盘图标（需要 Ubuntu 24.04 或 Debian 13 以上）
- 一键升级：点「立即更新」即可下载安装，安装包会先校验发布签名；命令行用 `sharetoken upgrade`

## 安全
- 本机管理接口需要密钥，桌面应用连接前会确认后台程序的身份
- 本地 OpenAI 兼容端点默认需要 API key，可在设置里或用 `sharetoken apikey` 管理
