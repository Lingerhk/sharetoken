ShareToken 每个版本带来的功能。

1.0.3

最新版本 2026-11-17

新功能

  • 本地端点同时提供 OpenAI Chat Completions、Anthropic Messages 和 OpenAI Responses 三种接口，Claude Code 和 Codex 可以直接使用；卖家的模型服务原生支持时原样转发，否则自动转换。
  • 私有中继：可以部署自己的中继，只为你列出的账号服务，别人访问你共享的设备时走你自己的服务器。文档提供 Linux 版中继程序和部署步骤。
  • 从 prompt 缓存读出和写入缓存的 token 单独计价；每个请求的预算默认 2 credit，可以在桌面应用的设置里调整，也可以选择只用原生支持请求接口的卖家。

稳定性提升

  • 三种接口之间的转换更完整：并行工具调用、结构化输出、思考设置、工具返回的图片和缓存用量都能正确往返。
  • 模型服务临时出错（过载、5xx、连接中断）时自动重试；额度用完或登录失效的提供商会暂停接单，不再让请求一个个失败。
  • 模型服务的回答中途断开时按失败处理，不再当作完整回答计费。

安全性

  • 平台抽检可以由用户的客户端转交：请求和回答全程加密，转交的客户端看不到内容，也不花 credit，卖家分不清抽检和真实请求。默认开启，可以在配置文件里关闭。
  • 抽检覆盖三种接口，由参考模型逐 token 核对卖家的回答。
  • 卖家节点不再执行买家请求里的托管工具；买家带来的请求头和 beta 开关按卖家的账号类型过滤。

1.0.2

2026-11-15

性能提升

  • 回答改用压缩后的二进制帧传输，经中继的流量降到原来的约 1/8；模型出字越快，省得越多。
  • 请求先压缩再发送，长对话历史的上传量降到约 1/4，大请求的首字更快。
  • 请求上限从 4 MB 提高到 32 MB，可以带截图等图片。
  • 同一段对话的后续请求优先回到上次的节点：连接已经建好，模型服务器的 prompt 缓存也更容易命中。

稳定性提升

  • 中继重启或网络切换时，正在输出的回答会在 60 秒内自动接上，不需要重发请求。
  • 模型长时间思考时，节点每 10 秒发一次心跳，不再被误判为卡死；买家的超时默认值改为 30 秒。
  • 点停止后，节点立即停止生成，只按已送达的部分计费。

安全性

  • 回答合并发送并补齐长度，请求按区间补齐，中继无法再从数据包大小推测每个 token 的长度。

1.0.1

2026-11-14

共享伙伴

  • 配对成为共享伙伴后，双方可以共享对方的 token 资源；伙伴节点不可用时，自动切换回 P2P 网络。
  • 可以限制给出去的量：每 24 小时最多给多少 tokens，以及伙伴最多占每个节点多少并发。并发比例设为 0 就是暂停共享。
  • 「只用伙伴的节点」：开启后不再到网络上购买。
  • 最多 5 个伙伴。邀请码只能用一次，有效期 1 到 7 天。
  • 入口：桌面应用「配对 → 共享伙伴」，或命令行 sharetoken partner。

登录与账户

  • 不再使用密码：输入邮箱和收到的验证码即可登录，新邮箱会自动注册。
  • 可以开启两步验证，管理员必须开启。
  • 收不到验证码时，可以写信给支持邮箱，由管理员提供一次性验证码。

桌面应用

  • 新界面：升级到 Wails v3，窗口更小，带侧边栏导航，底部状态栏显示连接状态、中继和延迟。
  • 菜单栏显示当前中继、延迟、共享状态和可用 credit。
  • Linux 支持托盘图标（需要 Ubuntu 24.04 或 Debian 13 以上）。
  • 一键升级：有新版本时点「立即更新」就能下载安装，安装包会先校验发布签名。命令行用 sharetoken upgrade。

安全

  • 本机的管理接口需要密钥才能访问；桌面应用连接后台程序前，会先确认对方的身份。
  • 本地 OpenAI 兼容端点默认需要 API key（sk-st-…）。可以在设置里或用 sharetoken apikey 查看、更换或关闭。

编程助手

  • sharetoken skill install：让 Claude Code 和 Codex 学会使用 ShareToken 客户端。文档里新增了「在编程助手中使用」一页。

开源

  • 以 MIT 许可证开源。网站和用户页面右上角加了 GitHub 链接。

1.0.0

首个版本 2026-11-09

网络

  • 共享本机的开源权重模型赚 credit，也能花 credit 调用别人的节点，同一个账户既能卖也能买。
  • 本地 OpenAI 兼容端点，支持 OpenAI 协议的工具改一下 base URL 就能用。
  • 节点不需要公网 IP，经中继打通连接；自动测 RTT 选最快的中继，故障时自动切换。
  • 接入在模型厂商开通的 API key 或订阅服务对外共享，买家可以用 Anthropic、OpenAI、Gemini 消息格式或 OpenAI 兼容协议调用。

安全

  • 请求封装加密，只有目标节点打得开，中继和协调器都看不到。
  • 响应带节点的 Ed25519 签名收据，买家自己核对，内容被改动会被发现。
  • 节点虚报用量时，买家只交出这一单的密钥作为证据，裁决后自动退款。
  • 协调器随机抽检，检查节点有没有偷换模型。抽检是概率性的。
  • 普通节点的运营者能读到 prompt，需要排除运营者时可以选 TEE 节点（AMD SEV-SNP / Intel TDX）。

配对

  • 卖家生成配对码发给买家；买家配对后只向配对的卖家购买，最多同时配对三个卖家。
  • 配对码有效期可选 1 天、7 天或 30 天，可以限制使用人数，随时撤销；买卖双方都能解除配对。
  • 私有模式：开启后卖家只为配对的买家服务，其他人看不到它的模型。
  • 桌面应用、命令行和用户页面都能管理配对。

客户端

  • 命令行客户端，支持 macOS、Linux 和 Windows。
  • 带图形界面的桌面应用，提供 macOS、Linux 和 Windows 安装包。
  • 网站和用户页面支持 10 种语言，桌面客户端支持英文和简体中文。
  • 有新版本时，桌面应用和命令行会提醒更新。
