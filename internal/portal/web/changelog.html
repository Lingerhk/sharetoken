ShareToken 每个版本带来的功能。

1.0.5

最新版本 2026-11-26

新功能

  • 和官方订阅并存：Claude Code 和 Codex 可以一键接入 ShareToken（桌面应用“设置 → 工具接入”里点“连接”，或运行 sharetoken connect claude / sharetoken connect codex），工具原来的 Claude、ChatGPT 登录照常保留。模型菜单里先列官方模型，后面是 ShareToken 网络的模型（以 st- 开头），同一个对话里可以随时切换。修改前会备份工具自己的配置文件，断开后按原样恢复。
  • Claude 订阅额度用完时自动续用：请求交给网络上最接近的模型继续，直到额度重置。默认开启，可以关闭或指定接手的模型。
  • Codex 额度保护：ChatGPT 订阅的额度窗口用到 95% 时暂停官方模型，并提示换成 st- 模型，以免 Codex Desktop 锁住输入框。可选的 Codex Desktop 无锁模式（macOS、Windows）让额度用完后输入框也不锁。
  • 登录系统时自动启动：桌面应用可以在登录时启动到托盘，命令行版用 sharetoken autostart on。“工具接入”里还能看到 Claude 和 ChatGPT 订阅的用量。
  • 客户端日志：日志写在数据目录的 logs 文件夹里并自动轮转，用 sharetoken logs 查看。
  • 崩溃报告：客户端崩溃时可以把报告发给平台，帮助我们修复问题。报告在保存前会去掉邮箱、key、地址和设备名等信息，待发的内容可以在设置里查看；随时可以关闭，欧洲经济区默认关闭。
  • Orca 插件（开发中）：在 Orca 的侧栏和状态栏里查看网络状态、额度、在售模型和请求记录，在 Orca 里启动的 Claude Code、Codex 可以按次走 ShareToken 网络，不改它们自己的配置。插件之后会放在单独的仓库发布，使用介绍会发在博客上。
  • 网站新增博客：分享 ShareToken 的最佳实践，比如和朋友共享 ChatGPT 订阅、自建中转站、和官方订阅并存，首页有入口。

其他变化

  • 一条共享伙伴邀请链接最多可以邀请 100 人，共享伙伴最多 100 人。
  • 本机接口列出的网络模型 ID 前面都加了 st-，以免和官方模型混淆；请求里带不带 st- 都可以。
  • 编程助手的 skill 增加了接入 Claude Code、Codex 并保留官方订阅的说明。
  • 使用文档按当前版本逐页校对更新。
  • 桌面应用概览：token 数量用 K、M 等单位显示，共享伙伴提供的模型标为“免费”。
  • 修复英文界面“工具接入”里的连接按钮显示为“Connections”，以及部分设置出错时只显示 HTTP 状态码的问题。
  • 修复一键升级刚开始时进度显示 NaN%、更新进行中重新打开详情还能再点一次的问题；本机时间不准导致设备签名被拒时，会提示检查系统时间，改对后半分钟内自动恢复。

安全加固

  • 本机接口：端点 key 现在只能用来调用模型，不能再访问客户端的管理接口；管理接口只接受 JSON 请求，网页无法跨站调用。预热里自定义的程序路径必须是完整路径，文件名为 claude 或 codex。
  • 登录：邮件验证码只能在申请它的浏览器标签页、应用窗口或终端里使用，别人拿到验证码也登录不了，别人乱猜也不会让你的验证码失效。请把客户端更新到最新安装包后再登录。
  • 结算：客户端核对过收据后自己向协调器确认，卖家换一张收据结算会全额退款并记一次败诉。请求中途停止、中断或被拒绝时，客户端会声明最多认可的金额，超出的账单不会自动支付。
  • 计费：prompt 用量的估算按请求的精确字段读取，并有按请求大小计算的下限，不能再被绕过。缓存价格有上限：缓存读不高于输入价，缓存写不高于输入价的 2 倍，超出的报价不被接受。
  • 网络和账户：中继限制每台设备、每个地址同时占用的连接数；协调器限制每个账户未开始的请求数；邀请和配对的尝试次数、通知邮件都有更严的频率上限。
  • 卖家节点和邮件：图片缩放、响应解码、嵌套请求都加了资源上限，收信解析更严格；升级了存在已知漏洞的依赖库，网络传输只保留 TCP 和 QUIC。

后续版本计划

  • 更新包签名格式的升级、Linux 一键更新缩小管理员权限的使用范围、官方订阅请求中断时的提示，以及上游适配、邮件和部署方面的其余加固，会在后续版本完成。

1.0.4

2026-11-20

新功能

  • 直连隧道：买卖双方都在路由器后面、无法直接相连时，可以经一条基于 Tailscale 协议（WireGuard）的加密隧道直连，请求和回答不再经过中继。不需要 Tailscale 账号、系统 VPN 或管理员权限。默认关闭，用 sharetoken tailnet on 或桌面应用里的开关开启，双方都开启才生效；隧道建不起来时照常走中继。
  • 隧道里的连接默认使用 QUIC，网络稳定时上传几 MB 的大请求明显更快；网络丢包或抖动较多（比如信号不好的 Wi-Fi）时可能反而更慢，可以改用 TCP（sharetoken tailnet on -transport tcp）。
  • 桌面应用的设置新增“网络”页：开关直连隧道，设置传输协议、等待时间和中转服务器，查看每条隧道的路径、协议、延迟和流量。状态栏显示隧道当前的连接方式和延迟。
  • 预热：Claude 和 ChatGPT（Codex）订阅的 5 小时窗口从重置后的第一次请求开始计时。客户端可以在你设定的时间发一条极小的请求，让窗口提前开始，工作时更早重置。本机的 Claude Code、Codex 和你出售的 Claude、ChatGPT 登录都可以预热，不经过 ShareToken 网络。在桌面应用的“设置 → 预热”里设置，或用 sharetoken warmup。
  • “共享”页的厂商卡片显示 Claude 和 ChatGPT 登录的用量窗口和预热设置。
  • 邀请链接：配对码和共享伙伴邀请码都附带一个链接，对方还没装客户端也能打开：页面显示是谁邀请，用邮箱登录或注册后一键接受，再按提示下载客户端。已经装了客户端的，可以在页面上直接打开应用确认。
  • “需要我确认”：生成配对码或伙伴邀请时可以勾选，对方使用后要你确认才生效。
  • 网页控制台的配对页也能管理共享伙伴，并能复制链接和整段邀请文案。

稳定性提升

  • 同一个公网地址后面可以有更多设备：中继和协调器对每个地址接受的连接数从 8 条提高到 32 条，办公室或家里多台设备共用一个出口时，不再有设备连不上中继。
  • 经中继的连接不再算在中继的地址上：协调器同时在线的用户数，以及经中继接单的卖家同时服务的买家数，不再受每个中继 32 条（卖家 8 条）连接的限制。
  • 第一次连接卖家更快：卖家的地址里有连不上的内网地址时，不再拖住经中继的连接，此前偶尔要多等约 10 秒。
  • 配对码改为 6 位，方便手输，链接是另外的 8 位令牌；配对码最长有效 7 天。输错的配对码和链接按账户、地址和每天限次，新账户次数更少；全站输错太多时，所有人暂停使用配对码一小时（链接照常可用），并通知管理员。

1.0.3

2026-11-17

新功能

  • 本地端点同时提供 OpenAI Chat Completions、Anthropic Messages 和 OpenAI Responses 三种接口，Claude Code 和 Codex 可以直接使用；卖家的模型服务原生支持时原样转发，否则自动转换。
  • 私有中继：可以部署自己的中继，只为你列出的账号服务，别人访问你共享的设备时走你自己的服务器。文档提供 Linux 版中继程序和部署步骤。
  • 从 prompt 缓存读出和写入缓存的 token 单独计价；每个请求的预算默认 2 credit，可以在桌面应用的设置里调整，也可以选择只用原生支持请求接口的卖家。
  • 运行 sharetoken models -codex 生成模型目录文件并在 Codex 配置里引用后，Codex 能拿到网络上模型的真实上下文窗口和推理档位，按时压缩对话。
  • 本地端点在 HTTP 上也支持 previous_response_id，OpenAI Agents SDK 等工具可以直接接入；Codex 的 WebSocket 会话可以中途打断。
  • 循环检测：模型原地重复输出，或反复调用同一个工具得到相同结果时自动截断，不再白白花费 credit。默认开启，可以在配置文件里关闭。

稳定性提升

  • 三种接口之间的转换更完整：并行工具调用、结构化输出、思考设置、工具返回的图片和缓存用量都能正确往返。
  • 模型服务临时出错（过载、5xx、连接中断）时自动重试；额度用完或登录失效的提供商会暂停接单，不再让请求一个个失败。
  • 模型服务的回答中途断开时按失败处理，不再当作完整回答计费。
  • Codex 走 HTTP 时，任务完成后立即结算，不再等待 24 小时的争议期。
  • 上下文超长时按各客户端能识别的方式回报，Claude Code 和 Codex 会自动压缩对话后继续。
  • 修复网络接口不可达时整个 QUIC 连接被关闭的问题；卖家刚开始回答就出错、或连接中断时自动换节点重试，慢模型靠心跳保持连接。
  • 与 Claude、Codex、Gemini 和各类 OpenAI 兼容服务的兼容性更好：被拒绝的请求写法会自动修正并记住，工具调用配对、图片尺寸、思考设置和工具 schema 都按上游的要求处理。
  • 单个请求超出卖家的每分钟额度时只让这个请求失败，不再让卖家暂停对所有买家的服务。

安全性

  • 平台抽检可以由用户的客户端转交：请求和回答全程加密，转交的客户端看不到内容，也不花 credit，卖家分不清抽检和真实请求。默认开启，可以在配置文件里关闭。
  • 抽检覆盖三种接口，由参考模型逐 token 核对卖家的回答。
  • 卖家节点不再执行买家请求里的托管工具；买家带来的请求头和 beta 开关按卖家的账号类型过滤。
  • 买家在 chat 请求里填写的 user 标识不再转发给卖家的模型服务。

1.0.2

2026-11-15

性能提升

  • 回答改用压缩后的二进制帧传输，经中继的流量降到原来的约 1/8；模型出字越快，省得越多。
  • 请求先压缩再发送，长对话历史的上传量降到约 1/4，大请求的首字更快。
  • 请求上限从 4 MB 提高到 32 MB，可以带截图等图片。
  • 同一段对话的后续请求优先回到上次的节点：连接已经建好，模型服务器的 prompt 缓存也更容易命中。

稳定性提升

  • 中继重启或网络切换时，正在输出的回答会在 60 秒内自动接上，不需要重发请求。
  • 模型长时间思考时，节点每 10 秒发一次心跳，不再被误判为卡死；买家的超时默认值改为 30 秒。
  • 点停止后，节点立即停止生成，只按已送达的部分计费。

安全性

  • 回答合并发送并补齐长度，请求按区间补齐，中继无法再从数据包大小推测每个 token 的长度。

1.0.1

2026-11-14

共享伙伴

  • 配对成为共享伙伴后，双方可以共享对方的 token 资源；伙伴节点不可用时，自动切换回 P2P 网络。
  • 可以限制给出去的量：每 24 小时最多给多少 tokens，以及伙伴最多占每个节点多少并发。并发比例设为 0 就是暂停共享。
  • 「只用伙伴的节点」：开启后不再到网络上购买。
  • 最多 5 个伙伴。邀请码只能用一次，有效期 1 到 7 天。
  • 入口：桌面应用「配对 → 共享伙伴」，或命令行 sharetoken partner。

登录与账户

  • 不再使用密码：输入邮箱和收到的验证码即可登录，新邮箱会自动注册。
  • 可以开启两步验证，管理员必须开启。
  • 收不到验证码时，可以写信给支持邮箱，由管理员提供一次性验证码。

桌面应用

  • 新界面：升级到 Wails v3，窗口更小，带侧边栏导航，底部状态栏显示连接状态、中继和延迟。
  • 菜单栏显示当前中继、延迟、共享状态和可用 credit。
  • Linux 支持托盘图标（需要 Ubuntu 24.04 或 Debian 13 以上）。
  • 一键升级：有新版本时点「立即更新」就能下载安装，安装包会先校验发布签名。命令行用 sharetoken upgrade。

安全

  • 本机的管理接口需要密钥才能访问；桌面应用连接后台程序前，会先确认对方的身份。
  • 本地 OpenAI 兼容端点默认需要 API key（sk-st-…）。可以在设置里或用 sharetoken apikey 查看、更换或关闭。

Skill支持

  • 增加ShareToken Cli端的Skill，可使用sharetoken skill install安装，AI Agent（如codex/claude）中可直接操作。

开源

  • 本项目以 MIT 许可证开源。

1.0.0

首个版本 2026-11-09

网络

  • 共享本机的开源权重模型赚 credit，也能花 credit 调用别人的节点，同一个账户既能卖也能买。
  • 本地 OpenAI 兼容端点，支持 OpenAI 协议的工具改一下 base URL 就能用。
  • 节点不需要公网 IP，经中继打通连接；自动测 RTT 选最快的中继，故障时自动切换。
  • 接入在模型厂商开通的 API key 或订阅服务对外共享，买家可以用 Anthropic、OpenAI、Gemini 消息格式或 OpenAI 兼容协议调用。

安全

  • 请求封装加密，只有目标节点打得开，中继和协调器都看不到。
  • 响应带节点的 Ed25519 签名收据，买家自己核对，内容被改动会被发现。
  • 节点虚报用量时，买家只交出这一单的密钥作为证据，裁决后自动退款。
  • 协调器随机抽检，检查节点有没有偷换模型。抽检是概率性的。
  • 普通节点的运营者能读到 prompt，需要排除运营者时可以选 TEE 节点（AMD SEV-SNP / Intel TDX）。

配对

  • 卖家生成配对码发给买家；买家配对后只向配对的卖家购买，最多同时配对三个卖家。
  • 配对码有效期可选 1 天、7 天或 30 天，可以限制使用人数，随时撤销；买卖双方都能解除配对。
  • 私有模式：开启后卖家只为配对的买家服务，其他人看不到它的模型。
  • 桌面应用、命令行和用户页面都能管理配对。

客户端

  • 命令行客户端，支持 macOS、Linux 和 Windows。
  • 带图形界面的桌面应用，提供 macOS、Linux 和 Windows 安装包。
  • 网站和用户页面支持 10 种语言，桌面客户端支持英文和简体中文。
  • 有新版本时，桌面应用和命令行会提醒更新。
