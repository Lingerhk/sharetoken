01

封装加密：prompt 只有目标节点打得开

每条消息都生成新的临时密钥，用节点在签名 Offer 里公布的公钥协商出一次性的对称密钥。密文还绑定作业 ID 和序号，无法重放到别的作业，也无法在流里调换顺序。

直连、中继和隧道用的是同一层封装加密：路径变了，能打开它的仍然只有目标节点。

临时 X25519 ECDH → HKDF-SHA256 → AES-256-GCM，外层再走 libp2p 加密通道；走隧道时外面还有一层 WireGuard

03

一单一钥：拿证据退款，只暴露这一单

节点虚报用量时，买家拒签，并交出这一单的密钥作为证据。裁决方核对收据、解密响应，用参考模型重新数 token 后自动裁决。其它作业各有各的密钥，依然没人打得开。

反过来，买家也赖不掉：有效的 Ack 可以直接结算，无 Ack 的单子过了 24 小时争议窗口即成交。

  1. 交出这一单的密钥
  2. 核对收据里的两个哈希
  3. 解密响应，用参考模型重新计数
  4. 申报 1,840 tokens · 实测 1,212 → 退款示意数字

逐 token 抽检

协调器随机下单，用参考模型逐 token 核对节点的输出；抽检请求可由用户的客户端代为发出，节点分辨不出。核对不符的节点暂停接单。

防蹭中继

门户签发 1 小时有效的 Ed25519 凭证，写明设备 peer ID。凭证被偷了也用不了。

防伪造

Offer、Ticket、收据、Ack 全部签名。peer ID 本身就是公钥，无需额外的身份目录。

使用

同一个账户，既能卖也能买。

客户端在本地开一个端点，同时兼容 OpenAI（Chat Completions、Responses）和 Anthropic Messages 协议。Claude Code、Codex 和其他支持这些协议的工具，改一下 base URL 就能用。

查看快速开始

用模型

非流式响应在收据验证通过后才交给你；流式响应边到边转发，结尾附验证结果。

# OpenAI 协议
curl http://127.0.0.1:9787/v1/chat/completions \
  -H "Authorization: Bearer $(sharetoken apikey -q)" \
  -d '{"model":"gemma-4-e4b","messages":[…]}'

# Claude Code 直接用本地端点
export ANTHROPIC_BASE_URL=http://127.0.0.1:9787
export ANTHROPIC_AUTH_TOKEN=$(sharetoken apikey -q)
claude

赚 credit

共享本机 Ollama 里的模型，或者你的 API key 和订阅（见下一节）。不需要公网 IP：能直连就直连，否则走隧道或中继。

# 共享一个本地模型
sharetoken share add gemma4:e4b -id gemma-4-e4b

# 上线接单，按实际 token 结算
sharetoken up

# 查看收益
sharetoken balance

配对：只和认识的人交易

卖家生成配对码或邀请链接发给买家，配对后买家只向配对的卖家购买，最多同时配对三个。卖家开启私有模式后，只为配对的买家服务。

# 卖家：生成配对码和邀请链接
sharetoken pair code -label team

# 买家：用配对码或链接配对
sharetoken pair join K7Q-F2M

# 卖家：只为配对的买家服务
sharetoken pair private on

共享伙伴：互相免费用

两个人结成伙伴后，互相使用对方的节点，不扣 credit，也不收手续费。可以限制每天给出的 token 数和占用的并发。

# 生成邀请码和邀请链接，发给对方
sharetoken partner invite

# 对方接受邀请
sharetoken partner join ABC-DEF

# 每 24 小时最多给伙伴 20 万 tokens
sharetoken partner set -limit 200000

配对和伙伴关系由协调器在撮合时执行，改客户端绕不过去。对方还没装客户端时，打开邀请链接就能注册并接受。桌面应用和门户里也能操作。 查看配对说明 · 查看伙伴说明

模型

本机模型、API key、订阅，都能共享。

接入你在模型厂商开通的 API key 或订阅服务。买家即可用 API key 调用，原生支持 Anthropic、OpenAI、Gemini 消息格式和 OpenAI 兼容协议。Claude 和 ChatGPT 订阅还可以定时预热，让 5 小时窗口提前开始计时、更早重置。

# 用 API key 添加，输入时不显示
sharetoken provider add anthropic
# 或者登录订阅账号，按提示在浏览器里完成
sharetoken provider login anthropic

# 看可用的模型，选一个共享
sharetoken provider models anthropic
sharetoken share add claude-fable-5-2 -provider anthropic

# 上线接单，按实际 token 结算
sharetoken up

请求以明文发给厂商，用量记在你的厂商账户上。共享前请确认厂商的服务条款允许这样使用。 查看完整说明

架构

四个角色，职责彼此隔开。

转发流量的看不到内容，记账的不碰数据路径，管账户的不撮合交易。

用户

买家和卖家在同一个进程里。能直连就直连，自动测 RTT 选最快的中继，中继故障时自动切换。

中继

官方中继分布在多个地区，你也可以自己部署只给自己账户用的私有中继。只转发加密流量，读不到明文，不记账。

协调器

撮合、结算、争议和抽检。不监听任何端口，只能经中继访问，暴露面很小。

门户

注册登录、API token、设备绑定、账单和中继登记，就是你现在看到的这个网站。

三种连接方式，自动回退

  1. 直连公网、IPv6 或打洞成功时，两端直接相连
  2. Tailscale 隧道先经 DERP 接通，几秒内换到两端之间的 WireGuard 直连双方都开启时生效，不需要 Tailscale 账号
  3. 中继两端都连不进来时经中继转发，中继只见密文
