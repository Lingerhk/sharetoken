# 桌面应用

桌面应用提供图形界面：登录、查看账户和网络状态，以及设置要共享的模型。

## 安装 {#install}

::: downloads desktop
:::

::: macos
1. 打开下载的 `.dmg`，把 ShareToken 拖到“应用程序”文件夹。Apple Silicon 和 Intel 的安装包不同，查看方法是点左上角苹果菜单，再点“关于本机”。
2. 第一次打开时，如果提示无法验证开发者：打开“系统设置 > 隐私与安全性”，在页面下方点“仍要打开”。应用还没有 Apple 公证。
:::

::: linux
安装包适用于 Ubuntu 24.04 或更新版本、Debian 13 或更新版本。用 `apt` 安装，它会一起装好需要的 GTK 和 WebKitGTK：

```bash
sudo apt install ./sharetoken-{{version}}-linux-<arch>.deb
```

`<arch>` 换成你下载的 `amd64` 或 `arm64`。之后可以从应用菜单打开 ShareToken。其他发行版可以用[命令行版](/docs/install)，再用下面的[不装窗口的图形界面](#browser-ui)。
:::

::: windows
1. 运行下载的安装程序。如果 SmartScreen 拦下，点“更多信息”再点“仍要运行”。应用还没有代码签名。
2. 按提示完成安装。它只为当前用户安装，不需要管理员权限，并在开始菜单和桌面添加快捷方式。
3. 需要 WebView2 Runtime。Windows 11 自带，Windows 10 没有时请从 Microsoft 网站安装。
:::

## 升级和卸载 {#upgrade}

有新版本时，窗口顶部会出现一行提示，带一句这个版本的说明；点“查看详情”可以看完整的更新内容和下载地址，“设置”里也可以随时“检查更新”。升级时下载新版本，像第一次那样安装，它会替换旧版本。卸载不会删除数据目录 `{{home}}`，账户和设备密钥都还在；要彻底清除，请再删除这个目录。

::: macos
卸载：退出应用，把“应用程序”文件夹里的 ShareToken 移到废纸篓。
:::

::: linux
卸载：

```bash
sudo apt remove sharetoken
```
:::

::: windows
卸载：打开“设置 > 应用 > 已安装的应用”，找到 ShareToken 后点“卸载”。
:::

## 窗口和后台服务 {#behaviour}

应用由两部分组成：窗口，以及真正做事的后台服务（`{{exe}} daemon`）。所有逻辑都在后台服务里，窗口只是显示它。

::: macos
- 菜单栏有一个图标，点击它可以看到连接状态、当前中继和延迟、共享状态和可用 credit，也可以打开窗口或退出。
- 关闭窗口（红色按钮或 `Cmd+W`）只是隐藏窗口。后台服务继续运行，共享和本地 API 不中断。
- 从菜单退出或按 `Cmd+Q` 才会退出应用。后台服务如果是应用启动的，会一起停止。
:::

::: linux
- 顶栏有一个图标（Ubuntu，以及其他能显示应用指示器的桌面）。点击它可以看到连接状态、当前中继和延迟、共享状态和可用 credit，也可以打开窗口或退出。关闭窗口只是隐藏，后台服务继续运行。
- 不显示应用指示器的桌面（比如没装指示器扩展的 GNOME）没有图标：关闭窗口就是退出应用，后台服务一起停止。想在这类桌面上一直在后台共享模型，请用[命令行方式运行](/docs/running#background)。
:::

::: windows
- 通知区有一个图标：左键打开窗口，右键打开菜单（连接状态、当前中继和延迟、共享状态、可用 credit、打开、退出）。Windows 11 可能把新图标收进 `^` 溢出区，你可以把它拖到任务栏上。
- 关闭窗口（X）只是隐藏窗口。后台服务继续运行，共享和本地 API 不中断。
- 从菜单退出才会退出应用。后台服务如果是应用启动的，会一起停止。
:::

再次启动程序只会唤回已有的窗口。

窗口左侧是导航：概览、共享、配对、记录，底部是反馈和设置。窗口底部的状态栏显示连接状态、当前中继和它的延迟，以及直连隧道的情况；延迟按快慢显示为绿色、黄色或红色。面板标题旁的“?”点开是这个面板的说明。

## 共享模型 {#share}

登录并连上网络后，点左侧的“共享”，它有三个标签：

- **厂商 API**：点“添加厂商”，选择厂商，填 API key 或用账号登录。保存后选择要出售的模型，填网络上的模型 ID 和价格。每个厂商可以单独停用、更换凭据或删除，每个模型可以测试、改价或移除。
- **本机模型服务**：在“设置”里填模型服务的地址，再点“添加模型”，应用会列出这个服务提供的模型。
- **状态**：至少有一个模型后，点“开启共享”开始接单。没有可出售的模型时，共享会自动关闭。
- **配对**（左侧的“配对”，“我的买家”标签）：点“生成配对码”，选择有效期（1 天或 7 天）、可配对的买家数，以及是否需要你确认，把配对码或链接发给你的买家（“复制链接”“复制邀请文案”）。这里列出你的配对码和买家，以及等待你确认的人（“确认”“拒绝”），可以撤销配对码或移除买家。勾选“私有模式”后，只为和你配对的买家服务。

价格的单位是每百万 tokens 多少 credit。API key 和登录令牌只保存在这台电脑上，页面只显示打码后的密钥。各厂商的说明和注意事项见[共享托管 API](/docs/share#providers)。

在“设置”的“调用”标签里可以勾选“只用原生支持请求接口的卖家”（Claude Code 的请求只发给模型服务器支持 Anthropic Messages 的卖家，Codex 的只发给支持 OpenAI Responses 的卖家，不做转换；见[原生和转换](/docs/use-models#native)），以及设置每个请求的冻结预算（默认 2 credit，按实际用量扣费）。两项都立即生效。

只想向认识的卖家购买时，用“配对”里的“我的卖家”：点“输入配对码”，填入卖家给你的配对码，或者粘贴他给的链接。见[只向认识的卖家购买](/docs/use-models#pairing)。

想和伙伴免费互相共享，用“配对”里的第一个标签“共享伙伴”。点“邀请伙伴”，选择有效期（1 天、3 天或 7 天）和是否需要你确认，把邀请码或链接发给伙伴；对方点“输入邀请码”，填入邀请码或粘贴链接。列表显示你的伙伴，以及最近 24 小时你给出和使用的 tokens，点“解除”结束伙伴关系。在“共享设置”里可以只用伙伴的节点、设置每日上限（每 24 小时的 tokens，所有伙伴合计）和伙伴最多占用每个节点并发的比例（0 表示暂停共享）。“可用模型”会标出伙伴提供的模型，“记录”里伙伴之间的作业显示“伙伴共享”。见[和伙伴互相共享（免费）](/docs/share#partners)。

在浏览器里点[邀请链接](/docs/share#invite-links)也能打开应用（链接页面上的“在 ShareToken 中打开”；安装包会把应用登记为 `sharetoken://` 链接的处理程序）。应用会切到前台，显示是谁邀请，并在接受之前问你；没有登录时，登录后再问。

## 直连隧道 {#tunnels}

“设置”里的“网络”页签是[直连隧道](/docs/running#tailnet)的开关：你和请求的另一方之间建一条加密隧道，不再经过中继。双方都开启才生效；否则，或者隧道建不起来时，请求照常走中继。勾选“直连隧道”立即生效，并显示它的设置：

| 设置 | 作用 |
|---|---|
| 传输协议 | 隧道里的连接跑在哪种协议上，只对本机发起的连接（买模型时）有效：QUIC（默认）或 TCP。共享模型时两种都接受。网络稳定时 QUIC 传大请求更快；网络丢包或抖动较多（比如信号不好的 Wi-Fi）又常发几 MB 的请求时，请选 TCP |
| 等待隧道 | 第一次请求某个卖家时，最多等多少毫秒让隧道建好（0 到 10000）。默认 0，不等：这个请求走中继，隧道建好后接管后面的请求 |
| 中转服务器 | 隧道起步、以及找不到直连路径时经过的服务器（DERP）。留空使用公共服务器；自己运行 DERP 的网络填自己 DERP 表的网址或文件。买卖双方要用同一组 |

“本机”一行说明买家能否经隧道到达这台电脑。“当前隧道”面板列出每条隧道：方向（到卖家、来自买家）、对方、路径（“直连”，或“中转”加 DERP 区域）、协议、延迟和流量。

状态栏用一句话显示隧道的情况：“未开启”；“已开启，暂无连接”；或者协议、路径、隧道数量和延迟，例如“QUIC 直连 × 2”。点击它会打开这里的设置。概览里的网络面板也显示同样的内容。

## 预热 {#warmup}

Claude 和 ChatGPT（Codex）订阅的 5 小时窗口从重置后的第一次请求开始计时。“设置”里的“预热”页签可以让窗口提前开始，工作时更早重置。它列出可以预热的账号：本机的 Claude Code 和 Codex，以及你在“共享”里用账号登录添加的 Claude、ChatGPT。每一行显示每日时间、窗口重置时是否预热、当前的用量窗口和最近一次预热的结果。点一行的“设置”修改，勾选“开启预热”后：

| 设置 | 作用 |
|---|---|
| 每日时间 | 本机时间，可填多个，用逗号分隔。到点时 5 小时窗口没在运行就发一条极小的请求；电脑睡眠等原因错过 1 小时以上就不补发 |
| 窗口重置时预热 | 周窗口，或 5 小时和周窗口，一重置就启动下一个。窗口已用完或正在用超额额度时不发送 |
| 模型 | 留空用最便宜的模型 |
| 程序路径 | 只有本机的 Claude Code 和 Codex 有：留空自动查找 `claude`、`codex` 命令 |

每行的“立即预热”马上发一条；“暂停所有自动预热”停止所有定时预热。预热只在客户端运行时进行，不经过 ShareToken 网络，也不花 credit。命令行用法见[预热](/docs/cli#warmup)。

## 不装窗口的图形界面 {#browser-ui}

命令行版自带同一套界面。运行：

```bash
{{exe}} daemon
```

然后用浏览器打开它打印的地址 `http://127.0.0.1:{{port}}/#key=…`，就可以在页面上登录。`#key=` 这一段让页面能操作客户端，`daemon` 每次启动都会变。和 `up` 的区别是：`daemon` 未登录也能运行，登录后才接入网络。

## 和命令行一起用 {#with-cli}

桌面应用和命令行版共用数据目录 `{{home}}`。应用运行时，`{{exe}} status`、`{{exe}} models`、`{{exe}} share add` 等命令都直接作用于它。同一个数据目录上不要再运行 `{{exe}} up`，否则同一把设备密钥会同时在线两次，客户端会报错退出。

::: macos
`{{exe}}` 在应用里面。要在终端直接用这个名字，先把它加入 PATH：

```bash
echo 'export PATH="/Applications/ShareToken.app/Contents/MacOS:$PATH"' >> ~/.zshrc
```

然后打开一个新终端。
:::

::: linux
安装包已经把 `{{exe}}` 放到 `/usr/bin`，可以直接使用。
:::

::: windows
安装程序已经把 `{{exe}}` 加入当前用户的 PATH，打开一个新终端就能使用。
:::
